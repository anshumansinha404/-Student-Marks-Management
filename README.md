# Student Marks and Grade Management System

## Project Description
This project is developed using the C programming language. It stores student names and marks, calculates average marks, assigns grades, and displays class statistics.

## Features
- Stores multiple student records.
- Uses arrays and structures.
- Accepts marks for multiple subjects.
- Calculates average marks.
- Assigns grades automatically.
- Displays student results.
- Finds the top-performing student.
- Calculates class average.

## Technologies Used
- C Programming
- Arrays
- Structures
- Functions
- Loops

## How to Run
1. Download the source code.
2. Open it in VS Code or any C compiler.
3. Compile the program.
4. Run the executable file.
